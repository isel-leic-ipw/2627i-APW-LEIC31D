# Part 1 starter project

This project contains starter files for the five JavaScript exercises in Part 1 and example tests for Exercises 1 and 2. The examples are provided in two assertion styles: Chai `expect` and Node.js `assert`.

## Setup

```shell
npm install
npm test
```

Alternatively, you may use `pnpm install` and `pnpm test`.

Run either assertion style independently with `npm run test:chai` or `npm run test:assert`.

The supplied tests are expected to fail until Exercises 1 and 2 are implemented. Students must add tests for Exercises 3, 4, and 5, as well as additional tests for Exercises 1 and 2.
